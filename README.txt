*** Before using this project: 
     - Make sure you have Ollama desktop application already installed in your pc/n
     - After installing Ollama, open windows command prompt and then write -> ollama run qwen2.5vl:7b command. This will install the AI model that needs to run the code./n
     - In the command prompt, write --> set OLLAMA_ORIGINS=*  and then write --> ollama serve . This will allow you to host the project from your pc to locally connected devices and run in the browser. 
       Keep the command prompt open to keep the host activated.
     - Once the above steps are done, go to the project folder from file explorer and from there, open windows terminal.
     - There, type --> .\run.ps1 which will run the project


*** Follow the steps carefully and enjoy
